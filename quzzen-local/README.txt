Локальная копия сайта quzzen.usite.pro (главная с 3D)

Запуск: двойной клик по START.bat — откроется http://localhost:8080
(нужен Python; открывать index.html двойным кликом нельзя — 3D-модули работают только через сервер)

Что где править:
  index.html                      — главная целиком (текст первого экрана собирает assets/js/header.js)
  assets/js/intro3d.js            — 3D-сцена: логотип, свет, фон, анимация
  assets/js/header.js             — шапка, меню, прелоадер, тексты первого экрана, печать слов
  assets/css/header.css           — стили шапки и первого экрана
  assets/css/home.css             — стили блоков главной
  assets/3d/logo-glass.glb        — модель логотипа

После правок нужные файлы из assets/ заливаются на хостинг по FTP в те же папки.
